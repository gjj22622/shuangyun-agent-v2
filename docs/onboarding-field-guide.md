# 新增客戶 — 14 欄位說明文件

> 此文件供**前端業務**與**客戶**閱讀，說明每個欄位要填什麼、為什麼需要、以及範例。

---

## 一、品牌基本（4 題）

### 1. 品牌名稱 `brandName`
- **要填什麼**：公司或品牌的正式名稱
- **為什麼需要**：系統會用這個名稱建立客戶檔案與品牌腦
- **範例**：`御美佳醫美診所` / `Lumen Coach` / `青木食堂`

### 2. 產業類別 `industry`
- **要填什麼**：品牌所屬的產業或領域
- **為什麼需要**：AI 會根據產業選擇對應的行銷策略模板（醫美的法規約束跟餐飲不同）
- **範例**：`醫療美容` / `B2B SaaS 教育訓練` / `在地餐飲` / `電商零售`

### 3. 負責人姓名 `ownerName`
- **要填什麼**：品牌的創辦人或主要決策者姓名
- **為什麼需要**：AI 的品牌腦會模擬這位決策者的思考方式（老闆 Agent）
- **範例**：`張育琴` / `Vivian Chen` / `陳青木`

### 4. 負責人 Email `ownerEmail`
- **要填什麼**：決策者的聯絡信箱
- **為什麼需要**：用於識別客戶身份與後續通知
- **範例**：`owner@yumeika.com`

---

## 二、品牌語調（2 題）

### 5. 語調風格 `toneOfVoice`
- **要填什麼**：希望品牌對外溝通的感覺，用幾個形容詞描述
- **為什麼需要**：AI 產出的所有文案都會遵守這個語調（品牌 Agent 會守門）
- **範例**：`專業、溫柔、有醫師背書感，避免過度推銷` / `專業但有數據感，像顧問不像業務` / `親切、生活感，像鄰居老闆跟你聊天`

### 6. 禁談主題 `bannedTopics`
- **要填什麼**：品牌絕對不能觸碰的話題或用語
- **為什麼需要**：AI 會把這些列入禁區清單，產出的內容會自動避開
- **範例**：`療效保證、未經核准的藥物、競品比較、政治敏感` / `醫療診斷暗示、保證 ROI 的承諾` / `外送平台抱怨、營養誇大`

---

## 三、行銷目標（5 題）

### 7. 主要目標 `primaryGoal`
- **要填什麼**：接下來 3-6 個月最想達成的一件事
- **為什麼需要**：AI 的所有策略建議都會聚焦在這個目標上
- **範例**：`三個月內把 LINE 好友從 1,200 人成長到 3,000 人` / `六個月 MQL 從 40 提升到 120` / `新分店開幕三個月達穩定來客`

### 8. 目標受眾 `targetAudience`
- **要填什麼**：你最想觸及的人是誰？年齡、職業、地區、特徵
- **為什麼需要**：AI 會根據受眾特徵調整內容的用字和風格
- **範例**：`30-50 歲雙北地區女性上班族與輕熟齡媽媽` / `員工 100-500 人的科技/製造業 HR 主管` / `方圓 2 公里內的上班族和學生`

### 9. 核心提案 `keyOffer`
- **要填什麼**：你提供的核心價值是什麼？客戶為什麼選你？
- **為什麼需要**：AI 產出的內容會反覆強化這個價值主張
- **範例**：`皮膚健康諮詢 + 微整療程套組，主打先諮詢再治療` / `一站式企業教練媒合 SaaS` / `每日手寫菜單 + 在地小農食材`

### 10. 目前痛點 `currentPainPoint`
- **要填什麼**：目前品牌在行銷上最大的困擾
- **為什麼需要**：AI 會優先解決這些痛點
- **範例**：`內容產出靠人工、文案合規常出包、客服回覆慢` / `業務跟行銷訊息斷層、轉換率追蹤不完整` / `貼文沒風格一致性、Google 評論被放戰`

### 11. 成功指標 `successMetric`
- **要填什麼**：怎麼判斷做得好不好？用數字衡量
- **為什麼需要**：AI 的品管機制會參考這些指標做品質判斷
- **範例**：`LINE +1800、官網表單月均 50、IG 觸及 +30%` / `MQL 月均 120、部落格流量 +25%` / `午市座位率 ≥80%、Google 4.6 星`

---

## 四、執行計畫（3 題）

### 12. 偏好渠道 `preferredChannels`
- **要填什麼**：品牌主要在哪些平台發布內容？（可多選）
- **為什麼需要**：AI 會針對你選的渠道產出對應格式的內容
- **選項**：`Facebook` / `Instagram` / `LINE` / `EDM` / `部落格` / `LinkedIn` / `YouTube` / `TikTok` / `Google Business`

### 13. 內容節奏 `contentCadence`
- **要填什麼**：每週/每月預計發多少內容？
- **為什麼需要**：AI 會按這個節奏排程，不會一次給太多或太少
- **範例**：`每週 3 篇 IG + 1 篇部落格 + 每天 1 則 LINE` / `每週 1 篇部落格 + 2 則 LinkedIn` / `每天 1 IG 限動 + 每週 4 貼文`

### 14. Campaign 時段 `campaignWindow`
- **要填什麼**：這波行銷活動的起訖時間
- **為什麼需要**：AI 會在這個時段內密集產出，時段外降低
- **範例**：`2026-04-15 to 2026-07-15` / `2026-04-15 to 2026-10-15` / `長期經營，無特定時段`
