## 1. 登入與角色

### 登入方式
在登入頁輸入 Token（由 Admin 發放），系統自動識別身份與權限。

### 三種角色

| 角色 | 權限 | 適用對象 |
|---|---|---|
| **Admin** | 所有功能 + 管理後台 + 團隊管理 | Jacky（創辦人） |
| **Operator** | 執行任務 + 新增客戶 + 編輯工作流 | 夥伴（Sophia、Barbie 等） |
| **Viewer** | 瀏覽所有頁面，不能執行任務 | 觀摩者 |

## 3. 新增客戶（Onboarding）

**路徑：** `/onboarding`
**權限：** Operator+

1. 填寫客戶基本資料（名稱、產業、聯絡信箱等）

## 5. 品牌腦 Builder

**路徑：** `/brand-brain-builder/:clientId`
**權限：** Operator+
**費用：** 組裝免費 / AI 品質檢查 ~$0.005（可選）

### 操作步驟

#### Step 1：上傳文件
上傳 5 種品牌文件（至少 3 種必要）：

| 文件類型 | 必要性 | 說明 |
|---|---|---|
| 商務開發紀錄 | 必要 | 客戶的商業模式、營收、目標 |
| 深度搜索報告 | 必要 | 市場分析、競品、定位 |
| 品牌邊界文件 | 必要 | 禁區、語調、品牌規範 |
| 週會紀要 | 選填 | 近期決策、方向調整 |
| 創辦人個性 | 選填 | 創辦人風格、溝通偏好 |

#### Step 2：組裝品牌腦（免費）
- 點擊「組裝品牌腦」
- 系統自動用預設模板 + 上傳文件 → 組裝 4 個 Agent
- **不花任何 AI Token**（純規則匹配 + 模板填充）

#### Step 3：檢視與微調
- 查看 4 個 Agent（Boss / Manager / Window / Brand）的 prompt
- 可手動編輯每個 Agent 的 prompt
- 編輯 strategyNotes（品牌策略筆記）

#### Step 4（可選）：AI 品質檢查
- 點擊「AI 品質檢查」按鈕（花 ~$0.005）
- AI 會評估品牌腦的品質並給出建議

#### Step 5：確認儲存
- 點擊「確認」→ 品牌腦版本 +1 → 寫入資料庫

### 模板 Prompt 語法
品牌腦的 prompt 支援 `{{ref:docType}}` 佔位符：
```
你是品牌總監。
## 品牌約束
{{ref:brand_boundary}}
```
執行時，系統會自動將 `{{ref:brand_boundary}}` 替換為該客戶上傳的品牌邊界文件原文。

## 6. 任務中心（執行任務）

**路徑：** `/demo`
**權限：** Operator+（執行需確認費用）

### 操作步驟

1. **選擇客戶**：下拉選單選擇品牌客戶
2. **選擇 Skill**：選擇要執行的 Skill（如「社群貼文企劃」「部落格長文」等）
3. **填寫任務標題**：描述這次任務的主題
4. **選擇模式**：
   - **指令組裝（免費）**：只看腦的指令組裝結果，不產出內容
   - **執行任務**：腦組裝指令 + Skill 產出內容（花 ~$0.005）
5. **可選：勾選 AI 品質審核**（額外 ~$0.005）
6. **點擊執行**

### 執行流程
```
指令組裝（0 token）→ Skill 執行（1 AI call）→ [可選 Review（1 AI call）]
```

### 結果顯示
- 內容初稿（可複製）
- 執行成本（Token 數 + USD）
- 如有 Review：品質評分 + 修改建議

### 品牌比較模式 `/demo/compare`
- 同時選 2-3 個客戶 + 同一個 Skill
- 系統並行產出 → 橫向比較不同品牌的風格差異

## 7. 工作流建構器

**路徑：** `/workflows`（列表）、`/workflows/:id`（編輯器）
**權限：** Operator+（建立/編輯）、Viewer+（瀏覽）

### 核心概念
工作流 = 腦 + 手的自動化流程。腦負責策略判斷（免費），手負責執行產出（花 token）。

### 兩種節點

| 類型 | 圖示 | 費用 | 用途 |
|---|---|---|---|
| 腦節點 | 🧠🎓🏷️ | **免費** | 策略判斷、指令組裝 |
| 手節點 | ✋ | ~$0.005/次 | Skill 執行、內容產出 |

### 三種腦
- **🧠 双云策略腦**（藍）：SOSTAC 方法論
- **🎓 師傅腦**（紅）：Jacky 案例庫
- **🏷️ 品牌腦**（琥珀）：每個客戶各一個

### 連線邏輯
- **腦↔腦**（紫色虛線）= 討論 → 產出綜合指令
- **腦→手**（灰色箭頭）= 指令下達
- **手→手**（灰色箭頭）= 產出傳遞

### 操作步驟
1. 在 `/workflows` 點「新增工作流」
2. 從左側面板拖放節點到 canvas
3. 從節點右側端點拖線到另一個節點左側端點（建立連線）
4. 點擊節點 → 右側面板設定（腦：綁定客戶 / 手：選擇 Skill）
5. 點「儲存」→ 工作流存入資料庫
6. 點「執行」→ 按拓撲順序逐步執行

### 執行邏輯
- 腦節點：從腦文件提取規則 → 組裝指令（0 token）
- 手節點：接收上游指令 → AI 執行（1 call）
- 並行節點同時執行
- 單步失敗不阻擋其他分支

### 歷史回饋
第二次執行同一工作流時，腦節點會讀取上次的執行結果，自動在指令中加入改進建議。

## 10. 排行榜（Token 激勵）

**路徑：** `/leaderboard`
**權限：** Viewer+

### Token 系統
- 執行任務會消耗 Token，也會賺取 Token
- 品質越高（Review 高分）、回饋越多 → 賺越多
- 累積 Token 可升級 Tier

### Tier 等級

| Tier | 升級門檻 | 每日上限 |
|---|---|---|
| Bronze | 初始 | 基本 |
| Silver | 累積 5,000 | 中等 |
| Gold | 累積 20,000 | 高 |
| Platinum | 累積 50,000 | 最高 |

### 排行榜顯示
- 本週 / 本月 / 歷史排名
- 前 3 名頒獎台
- Ramp-Up 加倍活動狀態

## 12. Skill 檔案管理

### Skill 存放位置
- **正式環境**：Google Drive（双云 Workspace）
- **開發環境**：本地資料夾

### Skill 檔案格式
```
skill-name/
├── SKILL.md          ← 主檔（frontmatter + prompt）
└── references/       ← 參考文件（可選）
    ├── 01-xxx.md
    └── 02-xxx.md
```

### SKILL.md 範例
```markdown
---
name: skill-name
layer: brain | hand
domain: sy | tbsa | jacky
version: 2.0
status: active
description: |
  Skill 描述...
---

# Skill 名稱

## 角色設定
你是...

## 執行邏輯
1. ...
2. ...
```

### 同步方式
1. **自動同步**：平台啟動時自動從 Google Drive 掃描
2. **手動同步**：Admin 後台點「同步 Skill」按鈕
3. **上傳**：Admin 直接上傳 .md 到 Google Drive

### References
- Skill 的 references/ 目錄下的 .md 文件會在執行時自動注入 prompt
- 例如 SOSTAC 企劃助理有 6 個 reference 文件（現況分析、目標設定...）

## 14. 常見問題

### Q: 為什麼「只問腦」模式是免費的？
腦的「思考」是規則匹配 + 模板填充，不呼叫 AI API。只有 Skill 的「執行」（產出內容）才花 Token。

### Q: 品牌腦跟 Skill 有什麼不同？
- **品牌腦**：每個客戶的品牌知識（約束、語調、禁區）→ 影響產出方向
- **Skill**：執行具體任務的工具（社群貼文、廣告文案等）→ 產出內容

### Q: 工作流的腦↔腦連線是什麼意思？
腦跟腦連線代表「討論」——前一個腦的指令會傳給下一個腦，讓不同視角的知識融合成更完整的指令。

### Q: 如何降低成本？
1. 不勾選 Review（省一半）
2. 先用「只問腦」確認指令方向，滿意再執行
3. 善用工作流的腦節點（免費）減少重複手動操作

### Q: 新增的 Skill 怎麼讓平台看到？
把 SKILL.md 放到 Google Drive 指定資料夾 → Admin 點「同步 Skill」→ 平台自動載入。

### Q: Token 用完了怎麼辦？
Token 是平台內部激勵系統。API 費用由双云統一支付。Token 用完代表今日配額已滿，隔天重置。
